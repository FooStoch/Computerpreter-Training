# Fingerspelling Classification

We used Python, OpenCV and Mediapipe! First, we collected images for A-Z using OpenCV and they are saved in ./data. Second, we created a dataset using MediaPipe to extract 21 hand landmarks, totaling 63 features, for each image. Third, we coded 4 different ML architectures with 4 hyperparameter specifications each. 

The Python version is 3.9.13. Make sure to install all the requirements in `requirements.txt` and then run the program in `inference_classifier.py`.
